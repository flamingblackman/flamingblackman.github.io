LLM State-Tracking Lab

An experiment in long-context state management: can a language model reliably maintain conditional logic and dynamic state across long sessions?

Gemini Custom Gem (system prompt) → structured Markdown session log → human audit → NotebookLM corpus

A prompt-engineered Google Gemini Gem encodes rules, conditional logic, boundary constraints, and faction clocks, emitting a structured state log every cycle.
